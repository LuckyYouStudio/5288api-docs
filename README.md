# 5288API 使用文档

5288API（sub2api 中转站）的注册、创建密钥、配置 Codex / Claude Code 的图文教程网页。

- 在线地址：https://luckyyoustudio.github.io/5288api-docs/
- 页面文件：`index.html`，插图在 `images/`
- 推送到 `main` 后由 `.github/workflows/pages.yml` 自动发布到 GitHub Pages（仓库 Settings → Pages 的 Source 需选择 **GitHub Actions**）

本地预览：直接用浏览器打开 `index.html` 即可。
